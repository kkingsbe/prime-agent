# Delegate-Tool Protocol (REQUIRED)

Delegate with the `delegate` tool. Do NOT implement anything yourself.

1. Call `delegate` at least twice — a 'draft' child and a 'tester' child.
   draft task: "Read .docs/instructions.md and the test file. Draft the full
   implementation, WRITE it to the exercise files, report the file paths."
   tester task: "Run the exercise test suite, report pass/fail counts and the
   failing test names."
2. Multiple delegate calls in ONE message run in parallel.
3. After a delegate call your turn ends automatically. Stop working. No polling.

Re-entry: read the draft's files and tester's report, integrate, run the tests
yourself, finish only when the test run passes.
